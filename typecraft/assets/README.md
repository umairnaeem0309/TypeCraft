# TypeCraft bundled assets

All files in this directory are generated procedurally by the project itself so
that TypeCraft ships with sensible defaults and does not depend on external
asset packs or network downloads.

## Avatars (`images/avatar_*.png`)

- `avatar_bear.png`
- `avatar_cat.png`
- `avatar_fox.png`
- `avatar_owl.png`

Generated by `scripts/generate_assets.py` using Pillow drawing primitives only.
No photographs, clip art, or third-party artwork are used.

## Fonts (`fonts/`)

The `fonts/` directory is intentionally empty at build time.
`ResourceManager.font()` falls back to the system default font when no custom
font is bundled, so TypeCraft works out of the box without shipping any font
files.

## Sound cues (`sounds/*.wav`)

- `key_click.wav` — short tick for each accepted keystroke
- `error.wav` — low tone for an incorrect keystroke
- `success.wav` — short fanfare on lesson completion
- `badge.wav` — celebratory chirp when a new badge is awarded

Generated by `scripts/generate_assets.py` using the `wave` module to write raw
PCM data. No external audio samples are included.

## Regeneration

If you need to recreate the assets (for example after a clean checkout), run:

```bash
python scripts/generate_assets.py
```

The script overwrites the files above in-place.
